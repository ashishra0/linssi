01 — How it works
A

Sees behind the login

Run linssi browser once and sign in. Every capture through it sees your app the way you do, not the sign-in form.

$ linssi browser
$ linssi --connect 9222 \
    localhost:3000/billing
B

Sized for the model

Every image fits a pixel budget. Tall pages come back as ordered, readable tiles instead of one strip too small to read. These are tiles of this page.

C

Tells you when it's wrong

Login redirects, blank pages, console errors and content that never settled come back as warnings, before the agent looks.

"final_url": ".../login?next=/settings",
"warnings": [
  "redirected to a login page"
]
02 — A real capture

Framed to the element, at 2x, in about a second.

$ linssi --selector '#plan' --padding 24 \
    localhost:3000/demo/billing/
Install

Give your agent eyes in a minute.

$ curl -fsSL https://linssi.app/install | sh
$ claude mcp add linssi -- linssi mcp

Codex: codex mcp add linssi -- linssi mcp. Cursor and other MCP clients: command linssi, args ["mcp"].
